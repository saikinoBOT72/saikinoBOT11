# saikinoBOT11

身内サーバー向けの Discord Bot。**サーバー内通貨**を軸に、

- 筋トレなどの**アクション報告でコインを稼ぎ**、
- **スロット / コイントス / じゃんけん対戦**で増やしたり溶かしたり、
- **各自が値段を決めて出品できるショップ**で売り買いする

までを一通り。操作は `/menu` から**すべてボタン**でできます。

**Cloudflare Workers + D1 で動くので、PCもサーバーも要りません。**クレジットカードの登録も不要で、無料枠だけで24時間動きます。導入もスマホのブラウザだけで完結します。

---

## 使い方は `/menu` だけ

```
🏠 メニュー
所持金 🪙 1,250 コイン （3 位）
連続報告 🔥 5 日 ／ 報告できること 5 種類 ／ 出品中 3 個

[💪 報告してかせぐ] [🎮 あそぶ] [🛍️ ショップ]
[💰 お財布]        [🔄 更新]  [⚙️ 管理]
```

ランキングは **お財布** の中、持ち物は **ショップ** の中にあります。

- 報告は**リストから選ぶだけ**。休憩中のものは「⏳休憩中」と表示されます
- 賭け金は **10 / 50 / 100 / 500 / 1000 のボタン**か「⌨️ 金額を入力」で自由入力（全角数字もOK）
- じゃんけんの相手・送金先は**メンバー一覧から選択**
- 出品や通貨設定は**入力フォーム**に書くだけ
- メニューは押した本人にしか見えません。報告・出品・購入・送金・大当たり・じゃんけんだけ、みんなに見えるようチャンネルに投稿されます

### できること

| | 内容 |
| --- | --- |
| 💪 報告してかせぐ | 管理者が決めたアクション（筋トレ・勉強など）を報告してコイン獲得。アクションごとに報酬・クールダウン・1日の上限を設定できます |
| 🔥 連日ボーナス | **アクションごと**に連続日数を記録します（筋トレ5日連続・勉強3日連続は別勘定）。「3〜6日目は毎日50、14日目以降は毎日200」のように**範囲で**決められます。1日空くとそのアクションだけやり直し。1日の区切りは 4:00（[変更可](#1日の区切り)） |
| 🏅 称号 | 条件を満たすと自動で贈られます。獲得した称号は**1つ選んで名前の横に表示**でき、報告の投稿やランキングにも出ます |
| 📢 定期発表 | 決まった時刻にランキングを自動でチャンネルに投稿します。「毎朝9時に筋トレの連続記録」「毎週月曜に今週稼いだコイン」など。1位に賞金を出すこともできます |
| 🎰 スロット | 3つ揃いで最大 x3000。還元率は約91%（残りはサーバーの取り分＝インフレ防止）。リールが左から1つずつ止まります |
| 🪙 コイントス | 表か裏を当てれば2倍。コインが回ってから結果が出ます |
| 🃏 ハイ&ロー | 次のカードが上か下か。当たるたび倍率が伸び、**いつでも降りられる**。最大20連勝まで。1回で降りれば約97%、粘るほど下がる |
| ✊ じゃんけん | 相手を指名して勝負。賭け金は開始時に預かり、勝者が総取り。あいこは5回まで再戦、時間切れは自動返金 |
| 🎲 チンチロ | 1対1。役の格で勝敗と倍率（最大×5）が決まる。**動く可能性のある最大額を先に預かる**ので、払えない状況が起きない |
| 🗳️ 予想大会 | お題と選択肢（2〜10個）を立てて、みんなで賭ける。**集まった全額を正解者で山分け**。人気のない選択肢を当てるほど儲かる。締切は任意（なしにもできる）。出題者は賞金の上乗せ・中止もできる |
| 🛍️ ショップ | 誰でも出品可。代金はそのまま出品者に入ります。在庫を決めれば売り切れで自動停止。**出品・購入・使用がチャンネルに流れます** |
| ✨ アイテムの種類 | 出品時に **使い切り**（持ち物から使える／使うと減る）か **ずっと残る**（記念品など）を選びます |
| 💰 お財布 | 所持金・送金・増減履歴・ランキング・称号・自分のデータ |
| ⚙️ 管理 | アクション／連日ボーナス／称号の作成、残高の調整、通貨名や賭け金上限の設定（サーバー管理権限を持つ人のみ） |

#### 予想大会の進め方

**🎮 あそぶ → 🗳️ 予想大会 → 🆕 お題を立てる** から、お題・選択肢（改行区切りで2〜10個）・締切・参加費を入れます。参加費を空欄にすると、各自が好きな額を賭けられます。**締切を空欄にすると締切なし**になり、出題者が「🔒 締め切る」を押すまで受け付けます。

```
① お題を立てる → チャンネルに投稿される
② みんなが選択肢のボタンを押して賭ける（1人1つ、選び直し・取り消しは不可／同じ選択肢への上乗せは可）
③ 締切がくると自動で締まる（出題者が手で締めることも可）
④ 出題者が「✅ 正解を決める」で正解を選ぶ
⑤ 集まった全額を正解者で山分け
```

山分けは**賭けた額に比例**します。参加費を決めた場合は全員同じ額なので等分になります（この場合は上乗せできません）。

参加者は、**すでに賭けた選択肢にだけ**あとから追加で賭けられます。選び直しも、賭けたぶんの取り消しもできません。

出題者は投稿のボタンから、いつでも **💰 賞金を上乗せ**（自腹を切って賞金プールを増やす）と **🚫 中止**（確認してから全額返金）ができます。

| 状況 | どうなるか |
| --- | --- |
| 正解者がいない | 全員に返金（上乗せは出題者に返金） |
| 参加者が1人だけ | 不成立で返金（同上） |
| 出題者が中止した | 全員に返金（同上） |
| 正解が決まらないまま7日 | 自動で取り消して全員に返金（同上） |
| 締切なしのまま1か月開きっぱなし | 自動で取り消して全員に返金（同上） |

出題者も賭けに参加できます。正解を決めるのは出題者なので、そこは身内の信頼でどうぞ（誰が何に賭けたかは掲示板に出ますし、コインの動きは履歴に残ります）。

**このゲームだけコインが増減しません。**参加者から集めた額を参加者に配るだけなので、サーバー全体の総量は変わりません。

#### アイテムの使い切りとずっと残る

出品するとき、最初に種類を選びます。

| 種類 | どうなるか |
| --- | --- |
| ✨ 使い切り | 買った人が **持ち物 → アイテムを選ぶ → 使う** で使えます。使うと1つ減り、「誰が何を使ったか」が説明つきでチャンネルに流れます |
| 📦 ずっと残る | 使う操作はなく、持ち物にずっと残ります。記念品や称号がわりのアイテム向き |

種類はあとから **自分の出品 → 種類を「〜」に** で切り替えられます（すでに買われたぶんは買った時点の種類のままです）。

#### 「1日」の区切り

日付が変わる時刻は `wrangler.jsonc` の `DAY_START_HOUR` で決めます。**4 にすると 4:00〜翌3:59 が同じ「1日」**になり、深夜2時に報告しても前の日の続きとして数えます。0（既定）なら 0:00 区切りです。

この区切りで数えるもの:

- 連続日数（連日ボーナス・称号・連続記録ランキング）
- アクションの「1日◯回まで」
- ランキングの「今日」「今週」（今週は月曜の区切り時刻から）
- 定期発表の「その日もう出したか」

**定期発表の「何時に出すか」は時計どおり**です（4時始まりでも「2:00に出す」は深夜2時に出ます）。ただしその発表は前の日ぶんとして扱われるので、日次の発表は区切り時刻より後（4時始まりなら4時以降）に置くのが素直です。

区切りを変えても、**すでに保存された記録は書き換わりません**。連続記録も途切れません（記録日のほうが新しく見える場合も「続いている」と判定します）。ただし変更した当日だけ、0時〜区切り時刻のあいだに報告していた人は、その報告が前日ぶんとして扱われます。**変更の反映は、深夜0時〜区切り時刻を避けて**行ってください。

#### 連日ボーナスの作り方（管理者）

**⚙️ 管理 → 🔥 連日ボーナス** で、まず対象のアクションを選びます。そのあと **➕ 追加・変更** で「何日目から」「何日目まで」「そのあいだ毎日もらえるコイン」を入れます。**「何日目まで」を空欄にすると、それ以降ずっと**になります。

```
3〜6日目    は毎日 50
7〜13日目   は毎日 100
14日目以降  は毎日 200
```

範囲が重なった場合は、開始日が後のもの（細かいほう）が優先されます。連続はアクションごとに数えるので、「筋トレは毎日、勉強は週末だけ」のような人もそれぞれ記録が伸びます。

#### 称号の作り方（管理者）

**⚙️ 管理 → 🏅 称号 → ➕ 新しく作る** で、まず条件の種類を選びます。

| 条件 | 例 |
| --- | --- |
| アクションの回数 | 筋トレ50回で「筋トレ王」 |
| アクションの連続日数 | 筋トレ30日連続で「鉄の意志」 |
| 報告の合計回数 | 合計100回で「継続の鬼」 |
| 所持金 | 10000で「富豪」 |

条件を満たした瞬間に自動で贈られ、チャンネルにも告知されます。

各自は **お財布 → 🏅 称号・連続記録** で獲得状況を見られ、**持っている称号から1つ選んで名前の横に表示**できます。表示した称号は、報告の投稿・ランキング・自分の画面に出ます。

#### 定期発表の作り方（管理者）

**⚙️ 管理 → 📢 定期発表 → ➕ 新しく作る** から、4ステップで設定します。

1. **どのチャンネルに**発表するか
2. **何のランキング**か
   - 総コイン数（いま誰が一番持っているか）
   - 稼いだコイン（期間内にどれだけ増やしたか）
   - アクションの回数（期間内）
   - アクションの回数（累計）
   - アクションの連続記録（いま何日続いているか）
3. **頻度** — 毎日／毎週（曜日を選ぶ）
4. **詳細** — 発表する時刻・何位まで出すか・1位への賞金・対象のアクション

毎日を選ぶと「今日」の集計、毎週を選ぶと「今週」（月曜始まり）の集計になります。複数の設定を並べられるので、「毎朝の筋トレ連続記録」と「毎週月曜の総合ランキング」を同時に動かせます。一覧から選べば**停止・再開・削除**もできます。

## 導入手順（スマホだけでできます）

やることは4つ。**Discord の設定 → Cloudflare の登録 → GitHub に情報を貼る → URLを繋ぐ**、それだけです。

### 1. Discord 側の準備

[Discord Developer Portal](https://discord.com/developers/applications) をブラウザで開きます。

1. **New Application** でアプリを作る
2. **General Information** のページで次の2つを控える
   - **Application ID**
   - **Public Key**
3. **Bot** のページで **Reset Token** を押してトークンを控える（一度しか表示されません）
4. 下のURLの `ここにApplicationID` を差し替えてブラウザで開き、自分のサーバーに招待する

```
https://discord.com/oauth2/authorize?client_id=ここにApplicationID&scope=bot+applications.commands&permissions=19456
```

### 2. Cloudflare に登録する

1. [Cloudflare](https://dash.cloudflare.com/sign-up) にメールアドレスだけで登録（**クレカ不要**）
2. ダッシュボードのURL `dash.cloudflare.com/××××××××` の `××××××××` の部分が **Account ID**。控える
3. 右上のアイコン → **My Profile** → **API Tokens** → **Create Token** → 一番下の **Create Custom Token**
   - 名前: なんでもよい（例: `saikinobot`）
   - Permissions に次の2つを追加する
     - `Account` / `Workers Scripts` / `Edit`
     - `Account` / `D1` / `Edit`
   - 作成すると表示される **APIトークン**を控える（これも一度きり）

### 3. GitHub にシークレットを登録する

このリポジトリの **Settings → Secrets and variables → Actions → New repository secret** で、控えた値を登録します。

| 名前 | 中身 |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | 手順2で作ったAPIトークン |
| `CLOUDFLARE_ACCOUNT_ID` | 手順2のAccount ID |
| `DISCORD_TOKEN` | 手順1のBotトークン |
| `DISCORD_PUBLIC_KEY` | 手順1のPublic Key |
| `DISCORD_APPLICATION_ID` | 手順1のApplication ID |
| `DISCORD_GUILD_ID` | （任意）自分のサーバーID。入れるとコマンドがすぐ反映されます |

登録できたら、**この変更を `main` ブランチにマージ**してください。プッシュされると GitHub Actions が自動で

- データベース（D1）の作成とテーブル準備
- Bot本体のデプロイ
- スラッシュコマンドの登録

まで済ませます。**Actions** タブで実行結果を開くと、一番上に Bot のURL（`https://saikinobot.〜.workers.dev`）が表示されます。

> マージ前に試したい場合は、Actions タブの「デプロイ」から手動実行できます（この画面は workflow が `main` にある場合のみ出ます）。

### 4. URLを Discord に繋ぐ

Developer Portal の **General Information** に戻り、**Interactions Endpoint URL** の欄に手順3で出たURLを貼って保存します。「All good!」のように保存が通れば接続完了です。

（保存できないときは、Actions のデプロイが成功しているか、`DISCORD_PUBLIC_KEY` が正しいかを確認してください。）

### 5. プライバシーポリシーのURLを設定する

`main` にマージしたあとであれば、Developer Portal の **General Information** にある **Privacy Policy URL** の欄に次のURLを貼れます（Discordの開発者ポリシーで求められています）。

```
https://github.com/<自分のアカウント>/<リポジトリ名>/blob/main/PRIVACY.md
```

> マージ前だとこのファイルが `main` に存在せず、URLが見つからないので弾かれます。**必ずマージのあとに設定してください。**

### 6. 遊びはじめる

サーバーで **`/menu`** を実行してください。まず管理者が **⚙️ 管理 → 📋 アクション管理 → 📦 おすすめを一括登録** を押すと、筋トレ・ランニング・勉強・早起き・自炊がすぐ使えるようになります。

## 運用のルール（大事）

**コインを現金・電子マネー・ギフト券などと交換しないでください。**

Discord は「現実の価値があるものを賭ける行為」をギャンブルとして規制していますが、換金できない遊び用のポイントはこれに当たりません。日本の賭博罪も「財物」性が要件なので同じです。逆に言うと、**コインに現金価値を持たせた瞬間に話が変わります**。

- ❌ 「1000コインで現金1000円」のような出品・交換
- ❌ コインを外部で売買する
- ⭕ 「肩たたき券」「1回おごり」など、身内の遊びの範囲のやり取り

未成年のメンバーがいる場合は、スロットやコイントスを使わない運用（管理メニューで賭け金上限を絞る、報告とショップだけ使う）も検討してください。

## プライバシー

保存しているのは Discord のユーザーIDと、このサーバーでの遊んだ記録だけです。**メッセージの本文は読み取れません**（そのための権限を持っていません）。

各自が **`/menu` → 💰 お財布 → 🔐 自分のデータ** から、保存内容の確認と削除をいつでも自分で行えます。詳しくは [PRIVACY.md](PRIVACY.md) を参照してください。導入時は、このファイルのURLを Developer Portal の **Privacy Policy URL** 欄に設定してください。

## 知っておいてほしいこと

- **Botはメンバー一覧で「オフライン」と表示されます。** 常時接続する作りではなく、コマンドが押されたときだけ Cloudflare 側が起きる方式のためです。動作には影響ありません
- **画像のアップロードには対応していません。** ショップの画像は「画像URL」を貼る形になります（Discord外の画像URLでもOK）
- 無料枠は1日10万リクエストまで、データベースは5GBまで。身内サーバーなら使い切ることはまずありません
- データは Cloudflare の D1 に入ります。消えて困る場合は `npx wrangler d1 export saikinobot --remote --output backup.sql` でバックアップできます（PCがある場合）
- コインの増減はすべて `ledger` テーブルに記録されるので、おかしくなったら管理メニューの「履歴を見る」で追えます
- データはサーバー（ギルド）ごとに完全に分かれています

## 開発

```bash
npm install
npm test    # Cloudflare にも Discord にも繋がずに検証（206件）
npm run check   # Worker がビルドできるか確認
```

テストは Discord から届く JSON を組み立てて画面遷移をなぞる方式です。

- `test/run-tests.mjs` — 通貨・報告・ショップ・じゃんけん・スロット・署名検証
- `test/menu-tests.mjs` — メニューの操作。**押しても反応しないボタンが無いか**、権限のない人が管理操作をできないかまで確認します

D1 の代わりに、テストでは同じ形をした better-sqlite3 製の偽物（`test/fake-d1.mjs`）を差し込んでいます。

### データベースを変更するとき

`migrations/` に新しい番号のファイルを足してください。

> ⚠️ **一度デプロイしたマイグレーションは絶対に書き換えないこと。**
> wrangler は適用済みかどうかをファイル名で覚えているため、中身を書き換えても再実行されません。
> さらに `CREATE TABLE IF NOT EXISTS` は既存のテーブルを素通りするので、
> 「新しい定義のつもりが古いテーブルのまま」という食い違いが起きます。
> 定義を変えたくなったら、必ず**新しい番号のファイル**で変更してください。

```
src/
  index.js            入口（署名の確認と振り分け、1分ごとの定期処理：時間切れ返金と定期発表）
  commands.js         スラッシュコマンドの定義（/menu と /help）
  context.js          DB・Discord API をまとめた道具箱
  discord/            Discord とのやり取り（署名検証・JSON組み立て・REST）
  menu/               画面
    router.js         customId `m:<画面>:<操作>:<引数>` の振り分け
    home.js           トップ画面
    report.js         報告
    games.js          スロット・コイントス・じゃんけん・チンチロ・予想大会の入口
    highlow.js        ハイ&ロー
    chinchiro-match.js チンチロの公開メッセージ
    poll.js / poll-board.js  予想大会
    rps-challenge.js  じゃんけんの公開メッセージ
    shop.js           ショップ
    wallet.js         所持金・送金・履歴
    privacy.js        自分のデータの確認と削除
    titles.js         称号と連続記録の確認・称号の切り替え
    admin.js          管理メニュー
  lib/                中身のロジック（通貨・報告・連日ボーナス・称号・ランキング・定期発表・ショップ・じゃんけん・スロット）
migrations/           D1 のテーブル定義
```
